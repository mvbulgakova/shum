# Разметка первой десятки пресс-релизов

Каждый блок — авто-подсказки паттерн-детектора + место, где ты правишь их руками.

**Легенда полей**
- **сигнал**: одно (или два) forward-guidance предложение, где ЦБ говорит про будущее
- **модальность**: необходимость / возможность / намерение / условная оценка / безусловное обязательство
- **вектор**: назван вверх / назван вниз / не назван / смешанный
- **ограничители**: степень («более плавное», «постепенно») и/или условия («в зависимости от», «в случае»)
- **hardness_v1**: паттерн-свёртка на скорую руку, −1..+1 (не финальный)

Формат «Правки»: если авто-подсказка неверна — впиши правильное значение;
если верна — оставь пустым (значит «согласен»). Так проще потом diff-нуть.
