# Тональность коммуникации ЦБ РФ и инфляционные ожидания

Датасет для исследования: пресс-релизы и резюме обсуждения ключевой ставки
Банка России, инфляционные ожидания инФОМ.

## Что здесь

```
dkp/
├── data/
│   ├── reference/
│   │   └── decisions.csv        # 103 решения ЦБ 2013–2026 (дата, ставка, шаг, направление)
│   ├── raw/
│   │   ├── press/YYYY-MM-DD.html    # сырые HTML пресс-релизов, 103 шт.
│   │   ├── summaries/*.html         # резюме обсуждения (2024+), 20 шт.
│   │   └── infom/latest.xlsx        # последний файл инФОМ (в нём вся история)
│   ├── interim/
│   │   ├── press_index.csv          # URL, статус, размер для каждого релиза
│   │   └── summaries_index.csv
│   └── processed/
│       ├── press.jsonl              # чистый текст + метаданные, one line per release
│       ├── press.csv                # короткая сводка (для Excel)
│       ├── summaries.jsonl          # резюме, чистый текст
│       ├── summaries.csv
│       └── infom.csv                # месячные ряды: наблюдаемая, ожидаемая, 5-летняя инфляция
├── src/
│   ├── fetch_press.py               # собирает корпус релизов
│   ├── fetch_summaries.py           # собирает резюме обсуждения
│   ├── extract_text.py              # HTML → чистый текст + автосигнал
│   └── extract_infom.py             # XLSX → месячные ряды
├── markup/
│   └── first_10_releases.md         # шаблон разметки на первую десятку
└── README.md
```

## Как воспроизвести

```
python3 -m pip install openpyxl
python3 src/fetch_press.py       # ~2 минуты, кэшируется в data/raw/press/
python3 src/fetch_summaries.py   # ~15 секунд
python3 src/extract_infom.py     # скачает свежий xlsx и распарсит
python3 src/extract_text.py      # соберёт processed/*.jsonl из сырья
```

Скрипты идемпотентны: уже скачанные HTML не перекачиваются.

## Что уже видно из данных

- **Средняя длина релиза**: росла с 2013 (~500 слов) до пика в 2021 (~1050 слов),
  потом резко упала до ~570 слов в 2024+. Это структурный сдвиг: ЦБ разделил
  публикацию на короткий релиз + подробное «Резюме обсуждения» (~30k символов).
  То есть тональность после 2024 нужно считать по объединённому корпусу
  релиз + резюме, иначе картина смещена.
- **Резюме обсуждения** существуют не с 2023, как сначала предполагалось,
  а с публикации 27.02.2024 (первое — по решению 2024-02-16). Итого 20 штук
  на конец июля 2026.
- **Ряды инФОМ** покрывают 2010-04 – 2026-07 (161 месяц). Три ключевых индикатора
  (наблюдаемая, ожидаемая 12м, ожидаемая 5л) — в одном файле `infom.csv`.
- **Автосигнал**: `signal_sentence` в `press.jsonl` находит forward-guidance
  предложение в 98/103 случаях. На парах 2024-10-25 («допускает возможность
  повышения») vs 2026-07-24 («будет принимать решения в зависимости от»)
  видно, что разметка модальности/вектора действительно даёт разный вес там,
  где словарь тональности показал бы одно и то же.

## Что делать дальше

1. Пройти по `markup/first_10_releases.md`, руками разметить модальность/вектор/
   ограничители — проверить, держится ли схема.
2. Только потом гнать словарь и pymorphy3 по всем 103 релизам.
3. Слить с `infom.csv` по месяцу заседания и построить корреляции.
