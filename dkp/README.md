# Тональность коммуникации ЦБ РФ и инфляционные ожидания

Датасет для исследования: пресс-релизы и резюме обсуждения ключевой ставки
Банка России, инфляционные ожидания инФОМ.

### Извлекаемые признаки (`src/features.py`, `data/processed/features.csv`)

По каждому релизу — forward-guidance предложение и по нему:
- **модальность** (5 категорий): условная оценка / возможность / необходимость /
  безусловное обязательство / намерение
- **вектор в сигнале**: up / down / none / mixed (по глаголам ужесточ*/смягч*/повыш*/сниж*)
- **число смягчителей** («плавно», «постепенно», «умеренно» и т.д.)
- **условность** («в зависимости от», «в случае», «при развитии ситуации» и т.д.)
- **hardness_v1** — арифметическая свёртка: знак(вектора) × вес(модальности) ×
  штраф(смягчителей) × штраф(условности). Диапазон [−1, +1].

### Analysis panel (`data/processed/panel.csv`)

Одна строка на решение (103 всего). Признаки сигнала + слепок инФОМ до/после
заседания + Δ ожиданий вокруг решения.

## Как воспроизвести

```
python3 -m pip install openpyxl plotly
python3 src/fetch_press.py         # ~2 минуты, кэшируется в data/raw/press/
python3 src/fetch_summaries.py     # ~15 секунд
python3 src/extract_infom.py       # скачает свежий xlsx и распарсит
python3 src/extract_text.py        # соберёт processed/*.jsonl из сырья
python3 src/features.py            # признаки forward-guidance
python3 src/build_panel.py         # объединит решения + фичи + инФОМ
python3 src/plot_exploratory.py    # fig/exploratory.html
```

Скрипты идемпотентны: уже скачанные HTML не перекачиваются.

## Что уже видно из данных

- **Средняя длина релиза**: росла с 2013 (~500 слов) до пика в 2021 (~1050 слов),
  потом резко упала до ~570 слов в 2024+. Это структурный сдвиг: ЦБ разделил
  публикацию на короткий релиз + подробное «Резюме обсуждения» (~30k символов).
  То есть тональность после 2024 нужно считать по объединённому корпусу
  релиз + резюме, иначе картина смещена.
- **Резюме обсуждения** существуют не с 2023, как сначала предполагалось,
  а с публикации 27.02.2024 (первое — по решению 2024-02-16). Итого 20 штук
  на конец июля 2026.
- **Ряды инФОМ** покрывают 2010-04 – 2026-07 (161 месяц). Три ключевых индикатора
  (наблюдаемая, ожидаемая 12м, ожидаемая 5л) — в одном файле `infom.csv`.
- **Автосигнал**: `signal_sentence` в `press.jsonl` находит forward-guidance
  предложение в 98/103 случаях. На парах 2024-10-25 («допускает возможность
  повышения») vs 2026-07-24 («будет принимать решения в зависимости от»)
  видно, что разметка модальности/вектора действительно даёт разный вес там,
  где словарь тональности показал бы одно и то же.

## Что делать дальше

1. Пройти по `markup/first_10_releases.md`, где авто-подсказки паттерн-детектора
   уже стоят — поправить неверные, подтвердить верные. Проверить, держится ли схема.
2. По результатам ревизии — поправить паттерны в `src/features.py` (сейчас
   `2022-02-28` даёт `direction=none` и `hardness=0`, потому что forward-guidance
   намеренно не называет вектор; это, возможно, правильно — но нужно решить,
   отдельная ли это категория).
3. Заменить hardness_v1 → v2 с честной морфологией через pymorphy3 (вид глагола,
   залог, наклонение), когда схема категорий устаканится.
4. Только после этого — эконометрика: local projections на Δ ожиданий инФОМ
   в окне ±3 месяца вокруг заседания, с контролями на факт-изменение ставки и
   ретроспективный сюрприз.

## Первое наблюдение (не выводы, но направление)

Разброс средних Δ ожидаемой инфляции инФОМ (месяц после заседания − месяц до),
разбитый по знаку `hardness_v1` (порог ±0.15):

|            | n   | Δ ожиданий, пп |
|------------|-----|----------------|
| hawkish    | 17  | **+0.35**      |
| neutral    | 57  | +0.11          |
| dovish     | 28  | **−0.08**      |

Знак и градиент идут в ожидаемую сторону, разница hawkish-vs-dovish ≈ 0.4 пп.
Но это корреляция, а не причинность: ястребиный сигнал обычно летит поверх
уже растущей инфляции, так что endogeneity нужно снимать (в п. 4 выше).
