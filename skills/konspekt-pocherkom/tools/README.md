# Как собран шрифт MariaHand и как его дополнить

Все скрипты запускаются из одной рабочей папки (не из `tools/`) и складывают туда промежуточные файлы.
Нужно: `pip install opencv-python-headless scikit-image scipy fonttools potracer pillow`.

1. **Сканы → картинки.** `pdfimages -j лекция.pdf src/l5` для каждой лекции, в `src/` получаются `l5-000.jpg` и т.д.
   Имя страницы без клетки (белая бумага) должно начинаться с `l4`, или поправить условие в `ink2.py`.
2. **Чернила без клетки.** `python3 ink2.py` → `ink2/*.npy` (прозрачность чернил), `ink2/*.png` для просмотра.
   Клетка и спираль тетради убираются, бледные чернила внизу страницы сохраняются.
3. **Строки и слова.** `python3 lines.py` → `layout.json`, `lines/`, `strips/*.png`.
   На `strips` каждая строка подписана номером, слова подчёркнуты попеременно красным и зелёным.
4. **Текст.** В `trans.txt` на каждую строку одна запись: `l5-000_03 | слово | слово | # | …`.
   Число слов должно совпасть с числом подчёркиваний; `#` означает «пропустить» (неразборчиво, формула, склеено).
   Записывать ровно то, что написано, с её сокращениями и знаками («ф.-ла», «мн-во»).
5. **Нарезка на буквы.** `python3 seg.py; python3 cand.py; python3 em.py; python3 build.py`.
   Скрипты ищут места разреза в связках (одиночный штрих в полосе строчных букв), подгоняют ширины букв
   и уточняют разрезы по эталонам букв. Результат — `glyphs.pkl`: экземпляр каждой буквы со своей
   базовой линией, высотой строчных и соседями слева/справа.
6. **Отбор глазами.** `python3 qa2.py а 28` рисует `qa.png`: все «а», от самых типичных к странным.
   Годные записываются через `python3 keep.py а "0-9,12,15"` (номера с картинки) в `keep.json`.
   Для нескольких классов сразу: `qa3.py "х,ю,ц"` и `keepm.py "х=1,2;ю=all"`.
7. **Шрифт.** `python3 make_font.py папка_для_шрифтов` собирает `MariaHand-A/B/C.otf`.
   Проверка готовых глифов: `python3 review.py "абв" папка/MariaHand-A.otf` → `review.png`;
   плохие варианты убираются через `python3 drop.py "а=3,7"` (номера вариантов с `review.png`), потом шрифт пересобирается.

Если добавляются новые лекции, шаги 1–6 выполняются для новых страниц. Номера в `keep.json` указывают на
экземпляры в `glyphs.pkl`, поэтому после пересборки `glyphs.pkl` весь отбор (шаг 6) делается заново на
полном наборе страниц: старых и новых.

`make_font.py` сам делает:
- обводку букв в кривые (контуры увеличенного в 4 раза скана) и выравнивание толщины линии между лекциями;
- удаление обрывков соседних строк;
- правила `calt`: сначала точная связка (тот же сосед слева и справа), потом сосед слева, потом справа, потом варианты по кругу;
- буквы ё и ъ, недостающие заглавные, знаки `; ! № « » " ' = +` из её штрихов;
- символы, которых нет вовсе, из Bad Script (`BadScript-Regular.ttf`, лицензия OFL).
